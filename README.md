## 100% Stacked Column Chart

### Overview

This visualization demonstrates the use of a **100% Stacked Column Chart in Microsoft Power BI** to analyze the proportional distribution of categories across different segments.

By normalizing each column to 100%, the visualization focuses on **relative contribution and percentage composition**, making it easier to compare category distributions across groups regardless of their absolute size.

### Analytical Focus

* Percentage-based category comparison
* Contribution and composition analysis
* Distribution analysis across segments
* Identification of proportional patterns
* Data interpretation and visual storytelling
* Business-oriented data visualization

### Key Takeaway

The 100% Stacked Column Chart provides a clear view of **how each category contributes to the whole**, making it particularly effective when the analytical objective is to compare proportions rather than absolute values.
